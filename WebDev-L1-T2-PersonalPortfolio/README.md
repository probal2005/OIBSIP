# ♿ Accessibility

The portfolio should respect:

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms;
    animation-iteration-count: 1;
    transition-duration: 0.01ms;
  }
}
```

Users who prefer reduced motion should receive a simplified experience.

---

# ⚡ Performance

Animations should prioritize:

* `transform`
* `opacity`
* GPU acceleration
* Lazy loading
* Optimized images
* Code splitting
* Lightweight effects

Avoid unnecessarily animating:

```text
width
height
top
left
margin
padding
```

Use transforms whenever possible.

# ⚙️ Installation

## 1. Clone Repository

```bash
git clone https://github.com/probal2005/probal2005.github.io.git
```

```bash
cd probal2005.github.io
```

---

## 2. Install Dependencies

Using npm:

```bash
npm install
```

Or using pnpm:

```bash
pnpm install
```

---

## 3. Run Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 4. Production Build

```bash
npm run build
```

---

## 5. Start Production

```bash
npm start
```
