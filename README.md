# 🚀 How to Run the Projects

## Clone the Repository

```bash
git clone https://github.com/probal2005/OIBSIP.git

## Enter the Repository

Bash

```
cd OIBSIP
```

## Run a Static Website

Open the required project folder and launch the `index.html` file in a browser.

You can also use the Live Server extension in Visual Studio Code.

## Run a React or Full-Stack Project

Bash

```
npm install
npm run dev
```

To create a production build:

Bash

```
npm run build
